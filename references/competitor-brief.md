# 竞品速查

> 各场景的主要竞品及其可攻击短板。每次评估新客户时，据此分析竞争格局和差异化策略。

| 竞品类型 | 代表 | 定位 | 可攻击短板 |

### 一、专业声学检测方案商 · 深度分析

这是 我方在售前阶段**最常遭遇的竞品类型**。三者各有侧重，但本质上都是"声学测量仪器"思维，与 我方的"AI 判断"思维形成根本差异。

#### 海德声科 HEAD Acoustics

| 维度 | 详情 |
|------|------|
| **背景** | 德国，全球声学与语音质量分析头部品牌，NVH 领域标杆 |
| **核心产品** | 人工头系统 (HMS) + ArtemiS SUITE 分析软件 + 声品质指标计算 |
| **典型客户** | 汽车 OEM NVH 实验室、家电噪声实验室、电声器件厂 |
| **价格带** | 单套人工头 ¥30-80 万 + ArtemiS 年 license ¥5-15 万 |
| **定位** | 声学实验室研究工具，非产线检测设备 |
| **可攻击短板** | |
| 🔴 实验室 vs 产线 | 人工头需要静音环境，车间噪音直接让测量失效。客户买了 ≠ 产线能用 |
| 🔴 给指标不给判断 | ArtemiS 输出响度/尖锐度/粗糙度等心理声学参数，但"这个产品 OK 还是 NG"得靠工程师自己定阈值——本质还是雇了个工具而不是替了一个人 |
| 🔴 工程师依赖 | 需要声学硕士以上才能正确解读 ArtemiS 的分析结果，产线 QC 组长学不会 |
| 🔴 节拍不匹配 | 实验室级分析通常 >2 分钟/样本，产线节拍 15-30s 无法满足 |
| 🟡 价格天花板 | 一条产线配一套人工头+授权 ≥50 万，且每年还要付 license，对产线经理来说 ROI 算不过 |
| 🟡 数据孤岛 | 每次测量生成独立分析文件，无产线级数据管理与追溯能力 |

**一句话拆招**：「海德声科是研发工具，我们做的是产线替代人的活儿。研发实验室买的设备，产线质检组长根本用不了。」

#### 理音 RION

| 维度 | 详情 |
|------|------|
| **背景** | 日本，精密声学测量仪器老牌，1944 年成立，亚洲市场渗透深 |
| **核心产品** | 精密声级计 (NL 系列) + 振动计 (VM 系列) + 多通道分析仪 (SA-A1) |
| **典型客户** | 日系车企及其供应商、电子制造、环境噪声监测 |
| **价格带** | 声级计 ¥2-8 万/台，多通道系统 ¥20-50 万 |
| **定位** | 高精度声学测量仪表，计量级精度 |
| **可攻击短板** | |
| 🔴 硬件公司基因 | 核心竞争力是传感器精度和计量校准，软件和 AI 几乎为零。官网主打产品是 1960 年代就有的声级计 |
| 🔴 单机思维 | 一个声级计 = 一个测点 = 一个人操作。大规模产线需要多通道同步+集中判断，理音方案天然不适配 |
| 🔴 无 AI 能力 | 没有 AI 模型、没有深度学习、没有异常检测算法——给的是 dB(A) 数值，不是 OK/NG 判断 |
| 🔴 日系供应链壁垒 | 日系客户倾向理音，但非日系客户（德系/美系/国产）品牌忠诚度不存在 |
| 🟡 传感器精度过剩 | 产线听音不需要 Class 1 计量级精度——AI 模型需要特征提取，不是小数点后三位的 dB 值 |
| 🟡 渠道依赖 | 严重依赖代理商销售，原厂对产线应用场景理解弱，售前响应慢 |

**一句话拆招**：「理音卖的是声级计里的奔驰，但产线上不需要一辆奔驰，需要的是一个会听、会判断的师傅。」

#### 西门子 LMS (Siemens LMS Test.Lab / Simcenter)

| 维度 | 详情 |
|------|------|
| **背景** | 比利时起家，2013 年被西门子收购，NVH 仿真+测试领域绝对巨头 |
| **核心产品** | LMS Test.Lab（测试）+ Simcenter（仿真）+ SCADAS 采集前端 |
| **典型客户** | 全球汽车 OEM 的 NVH 部门、航空航天、重工 |
| **价格带** | SCADAS 硬件 ¥15-50 万 + Test.Lab 年 license ¥10-30 万 |
| **定位** | R&D 级 NVH 开发平台，对标 ANSYS / Nastran 的声振仿真体系 |
| **可攻击短板** | |
| 🔴 R&D 平台非产线工具 | LMS 核心价值在"设计阶段仿真预测 NVH 性能"——产品已造出来进入质检环节时，LMS 没有角色 |
| 🔴 PhD 级操作门槛 | LMS 工程师通常是 NVH 博士，测点布置、传递路径分析、模态分析……产线 QC 团队没有这个人力配置 |
| 🔴 价格体系不透明 | 西门子工业软件采用模块化定价 + 年维护费，多模块叠加后单线成本极易突破 ¥100 万 |
| 🔴 产线场景水土不服 | SCADAS 前端是通用采集平台，没有任何产线化改造——无 MES 对接、无扫码枪联动、无自动判定输出、无产线节拍适配 |
| 🟡 西门子体系绑定 | 已在用 Siemens PLC/MES/NX 的客户会有协同优势，但智能工厂没在用西门子的客户，LMS 就是一座孤岛 |
| 🟡 响应速度慢 | 大公司决策链 + 原厂直销模式，一个工位级改造需求走原厂流程可能 3-6 个月没回音 |

**一句话拆招**：「LMS 帮你设计出更安静的产品，我方帮你把造出来的产品一个个听一遍。这是完全不同的两个赛道。」

### 三家总结对比

|  | 海德声科 HEAD | 理音 RION | 西门子 LMS |
|------|------|------|------|
| **核心基因** | 声品质研究 | 声学测量仪表 | NVH 仿真+测试 |
| **主力场景** | 研发实验室 | 现场/实验室测量 | R&D 开发 |
| **AI 能力** | 开始探索心理声学 AI | 几乎为零 | 工业 AI（质量预测），非声学专用 |
| **产线适配** | ❌ 需要静音环境 | ❌ 单机操作 | ❌ R&D 平台 |
| **操作门槛** | 声学硕士 | 培训 1-2 天 | NVH 博士 |
| **单线成本** | ¥50-100 万+ | ¥20-80 万 | ¥100 万+ |
| **最致命短板** | 实验室搬不到产线 | 只给数值不给判断 | 根本不是做产线质检的 |

**对 我方的通用打法**：
这三家的存在**不是坏事**——客户已经知道"声学检测有价值"，只是买错了形态。我方的切入逻辑是「你已经有声学意识了，现在缺的是把它产线化、AI 化、去人化」，而不需要从零教育市场。

### 二、通用 NVH 测试设备商 · 深度分析

这类竞品核心特征是"硬件公司基因"：传感器 + 采集前端 + 基础分析软件，但数据判断靠人。在产线听音场景中不如专业声学方案商常见，但在**精密制造/军工/航空航天**等对硬件品牌有审计要求的领域是主要竞品。

#### B&K / HBK (Hottinger Brüel & Kjær)

| 维度 | 详情 |
|------|------|
| **背景** | 丹麦，1942 年成立，全球最老牌的声学与振动测量公司。2019 年被 Spectris 收购，与 HBM 合并为 HBK。近年收购 Discom 杀入产线 EOL 检测 |
| **核心产品** | PULSE 分析平台+ LAN-XI 采集前端 + 各类测量麦克风/加速度计 + Discom NVH EOL 系统 |
| **典型客户** | 汽车 OEM NVH 部门、航空航天、家电、电声、高校研究所 |
| **价格带** | LAN-XI 模块 ¥8-20 万/通道，PULSE 软件 ¥10-30 万/年，Discom EOL 系统 ¥80-200 万/线 |
| **定位** | 从实验室声学测量 → 产线 EOL NVH 检测的"全链条"供应商 |
| **可攻击短板** | |
| 🔴 Discom 只覆盖特定场景 | Discom 的 EOL 方案专攻齿轮箱/车桥/电机 NVH 下线检测，只适用于旋转机械噪声——不是通用"听音工替代"。面对风扇异音、座椅导轨滑动异响、出风口叶片异音等接触式声学场景，Discom 没有产品 |
| 🔴 分析仍靠工程师 | PULSE 平台定位是"给专家用的工具"，不是"替代专家的 AI"。有丰富的数据可视化，但没有 OK/NG 判定模型 |
| 🔴 品牌溢价严重 | B&K 是声学界的"爱马仕"——一个 1/2 英寸自由场麦克风 ¥2-5 万，传感器单价是同规格国产 10-20 倍。产线大规模部署时成本失控 |
| 🔴 合并后组织臃肿 | HBK 由 7+ 次收购拼成（B&K + HBM + Discom + nCode +……），产品线之间整合度有限，产线客户需求传递路径过长 |
| 🟡 Discom 收购是双刃剑 | 一方面说明 HBK 认可产线检测市场价值——验证了 我方的方向；另一方面 Discom 在中国的渠道和服务覆盖极弱，主要客户在欧洲 |
| 🟡 非 NVH 产线无兴趣 | HBK 的产线方案严重绑定"旋转机械 NVH"这一个场景。非旋转件（如座椅、内饰件、空调出风口、电子开关手感）的异音检测不在他们的雷达上 |

**一句话拆招**：「B&K 是声学测量行业的黄金标准——但黄金标准是用来标定实验室的，不是用来跑产线的。他们收购 Discom 恰恰证明产线检测是个好市场，但 Discom 只管齿轮和电机的噪声，面对座椅导轨或空调出风口的异音，他们也没什么好办法。」

### 三、机器视觉厂商 · 深度分析

机器视觉厂商不是声学竞品，但在客户预算争夺中**经常被拿来和我们并列比较**。客户采购经理的典型心理：「我有这笔预算，是买视觉检测还是买声学检测？」这本质上是预算争夺而非技术竞品。

#### 基恩士 KEYENCE

| 维度 | 详情 |
|------|------|
| **背景** | 日本，1974 年成立，全球传感器与机器视觉之王。市值超 ¥1 万亿 RMB，直销模式标杆 |
| **核心产品** | CV-X / XG-X 系列视觉系统 + LJ-V 激光轮廓仪 + 各类光电/激光传感器 |
| **典型客户** | 几乎覆盖所有制造业——汽车、电子、半导体、食品、制药…… |
| **价格带** | 视觉系统 ¥5-30 万/套，年维护费另计 |
| **定位** | 工厂自动化检测基础设施，产线标配 |
| **与 我方的关系** | |
| 🟢 互补 > 竞争 | 视觉检测外观/尺寸/缺陷，声学检测异音/振动/异响——两者检测的是不同物理维度。绝大多数产线同时需要两种能力 |
| 🔴 预算竞争 | 基恩士在客户采购体系中地位极强（"先买基恩士再看别的"），这可能挤压声学检测的预算空间。需要明确论证"视觉做了外观，但你还是要人听异音" |
| 🟡 基恩士不做声学 | 基恩士的产品路线图中至今没有声学/振动检测。如果有一天他们进入这个领域（通过收购或自研），将是 我方最可怕的竞争者——他们有 30 万+ 产线客户触点 |
| 🟡 销售模式启示 | 基恩士的"顾问式直销 + 免费 demo + 快速响应"是 我方可以学习的，但他们的规模（全球 10,000+ 销售人员）暂时无法复制 |

**一句话拆招**：「基恩士替了产线上用眼看的人，我方替了产线上用耳朵听的人。你们的质检工位还需要一个人来听异音，这就是我们存在的价值——客户不会因为买了基恩士就取消了听音工。」

#### 康耐视 Cognex

| 维度 | 详情 |

### 四、自研方案 · 深度分析

企业自研基于 LabVIEW 的声学测试系统在**中国制造业极为普遍**，特别是在 2010-2020 年工厂自动化浪潮中搭建了大量此类系统。这看似"免费"但隐性成本极高。

#### LabVIEW + 麦克风 / 自搭系统

| 维度 | 详情 |
|------|------|
| **背景** | NI LabVIEW 在中国制造业自动化浪潮中渗透极深，大量工厂在 2010-2020 年间自搭了基于 PXI/PXIe + LabVIEW 的简易声学采集系统 |
| **典型形态** | 一个 NI 采集卡 + 一只麦克风/加速度计 + 一个 LabVIEW VI 程序（多半是离职工程师留下来的） |
| **典型客户** | 任何有自建技术团队的工厂——从汽车 Tier 1 到家电到电子制造 |
| **价格带** | 硬件 ¥3-10 万（一次性），软件"免费"（实际上是前人开发成本沉没） |
| **可攻击短板** | |
| 🔴 关键人风险 | 系统是靠一个工程师的 LabVIEW 技能搭的。这个人离职后，留下的 VI 代码没人敢改——"改坏了产线停线谁负责？"这是工厂经理最怕的场景 |
| 🔴 无 AI 能力 | LabVIEW 方案能做的最多是：FFT → 设 RMS 阈值 → 超阈值报警。复杂的异音模式（间歇性/非稳态/多频段）完全无法识别。准确率通常 70-85%，远低于 AI 方案 95%+ |

| 🟡 切入策略 | 不攻击他们的系统，而是先用免费 demo 证明 AI 方案准确率大幅高于现有自研方案，然后算一笔账：「你养维护这套系统的工程师一年的工资，够买我们一条线的方案」 |

**一句话拆招**：「你现在的 LabVIEW 系统是一笔技术债——它看起来还能跑，但维护它的人力、限制它的天花板、以及那个唯一懂它的工程师离职的风险，加起来远比你想象的多。我们把它替换成标准化的 AI 方案后，这些风险归零。」

### S03 深度分析

#### 人工敲击听音（当前主流方案）

| 维度 | 详情 |
|------|------|
| **方式** | 工人用小锤敲击工件，凭敲击声的回声特征（清脆/沉闷/有无杂音）判断是否有裂纹/疏松/脱粘 |
| **应用场景** | 刹车片、陶瓷件、粉末冶金件、复合材料、金属铸件、铁轨、车轮——任何"敲一下听声音"的场景 |
| **准确率** | 据公开研究，人工敲击探伤准确率约 80-90%，取决于工人经验和疲劳程度 |
| **人员** | 通常需要 3 年以上的熟练工 |
| **可攻击短板** | |
| 🔴 主观不一致 | 同一工件不同人敲结论不同，同一人上午敲和下午敲标准不同（疲劳衰减）。没有数字化的标准——"老师傅说不行就是不行" |
| 🔴 疲劳衰减 | 一天敲 500+ 次，听觉注意力和手臂力度保持不了一整个班次。研究表明听觉疲劳后误判率上升 15-25% |
| 🔴 无法追溯 | "谁敲的、怎么敲的、为什么判定 NG"——全部在人脑子里，没有任何数据记录。一旦客诉需要追溯到检测环节，零证据可查 |
| 🔴 老师傅退休=技能消失 | 新一代年轻人不愿做重复体力劳动，培训 3 年的敲击听音工越来越难招 |
| 🔴 无量化标准 | 什么是"听起来闷"？什么是"有杂音"？没有 dB 值、没有频谱、没有特征参数。无法向客户证明"我们的检测标准是一致且可量化的" |
| 🟡 成本极低 | 工具成本=一把锤子，不需要额外投资。这是客户犹豫替换的最大心理障碍——"明明免费就能做，为什么要花几十万买设备？"需要从客诉损失和追溯合规的角度破局 |

**一句话拆招**：「敲了 20 年的老师傅，下午 3 点敲的第 500 个工件，和你早上 8 点敲的第一个工件，判断标准已经不是同一个了。敲击听音的问题是——你不知道什么时候开始听不准了。我方把这个过程数据化、可追溯、不受疲劳影响。」

#### 超声相控阵 (Ultrasonic Phased Array)

| 维度 | 详情 |
|------|------|
| **背景** | 成熟的 NDT（无损检测）技术，利用多阵元超声探头电子扫描实现内部成像 |
| **代表厂商** | Olympus (Evident) / GE / 汕头超声 / 中科创新 |
| **价格带** | 便携式 ¥20-60 万，在线系统 ¥80-200 万+ |
| **定位** | 高精度内部缺陷成像，焊缝检测的标配 |
| **适用场景** | 焊缝、厚壁件、复合材料分层——需要看"内部结构"的场景 |
| **可攻击短板** | |
| 🔴 需要耦合剂 | 超声必须通过耦合剂（凝胶/水）传递到工件。这道工序在产线上极其麻烦——涂胶→检测→擦胶，额外增加 2-3 个步骤和 30-60 秒 |
| 🔴 操作复杂 | 探头的角度、聚焦深度、增益设置……需要 NDT 二级以上资质的操作员。产线 QC 组长不具备这个资质 |
| 🔴 节拍慢 | 单个检测点通常 2-5 分钟。即使自动扫查系统，最快也需要 30-60 秒——远超产线 15s 节拍要求 |
| 🔴 不适合复杂形状 | 曲面/异形/薄壁件的耦合困难，信号一致性差 |
| 🟡 深度探伤刚需场景 | 如果需要检测的是工件**内部 2mm 以下**的微裂纹/气孔，声学敲击确实做不到。此时超声是必要方案，我方应主动承认并界定边界："我们覆盖表面近表面缺陷，深层缺陷用超声" |

**一句话拆招**：「超声相控阵是深度探伤的利器，但它需要涂耦合剂、需要持证操作员、检测一个工件要 2 分钟。等超声做完这一批，产线已经停了 4 个小时了。我方的敲击探伤只需要敲一下，15 秒出结果——适合产线上每一件都检的快节奏。」

## 通用竞争策略

1. **不是卖硬件，是卖判断力**：所有传统方案给的是"数据+工具"，我方给的是"结论"
2. **设备→产品闭环**：传统方案只监控设备或只检测产品，我方可以把两者打通
3. **轻量化部署**：外挂式传感器，不停机、不改造设备
4. **案例壁垒**：已有 消费电子标杆客户的产线稳定运行验证
5. **不是取代，是互补**：面对超声/X 光/视觉等不同物理维度的检测手段，主动界定边界、定位互补，不要和客户的已有投资争"谁更好"
6. **用好竞品的存在**：HEAD/LMS/RION 的存在教育了市场，谛声/联丰迅声验证了赛道——竞品的存在恰恰说明"AI+声学"是真需求，我方要做的是在**产线质检**这个最肥的细分场景里做到第一
