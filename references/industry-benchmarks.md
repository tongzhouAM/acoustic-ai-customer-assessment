# 分行业 ROI 基准

> 用于客户评估中的 ROI 论证。不同行业的成本结构和回报逻辑差异巨大，ROI 测算必须因行业制宜。

---

## 一、汽车零部件

| 参数 | 数值 | 说明 |
|------|------|------|
| 听音工年薪 | ¥8-12 万 | 含五险一金 |
| 典型人工替代量 | 集中式 5-30 人/房；分散式 1-3 人/线 × 多线 | 集中式=听音房（出风口/电机型）；分散式=线端工位（座椅型），按工位总量累计 |
| 客诉/召回单次损失 | ¥50-500 万+ | 主机厂罚款 + 召回物流 + 返工 |
| 客户审核通过率提升 | 5-15% | 数据追溯能力是审核加分项 |
| 投资回收期 | 3-12 月 | 基准 8-10 月 |
| ROI 最高来源 | 人工替代 (40-60%) + 客诉降低 (30-50%) | |

**汽车零部件是 我方ROI 最高的行业**——客诉和召回的惩罚成本是放大器的关键。

| 参数 | 数值 | 说明 |

| 部件级空缺 | 滑轨/调角器/驱动器异音 EOL 设备为行业空白位 | 在位耐久/力值设备成熟但无 AI 异音判定 |

## 二、半导体精密零部件

| 参数 | 数值 | 说明 |
|------|------|------|
| 单件报废损失 | ¥1-50 万 | 真空腔体/石英件/陶瓷件单价高 |
| 设备非计划停机损失 | ¥10-50 万/次 | 含交付延迟违约金 |
| CNC 单机年维护费 | ¥3,000-10,000 | 设备预测性维护市场参照 |
| 人工替代量 | 通常 < 10 人/厂 | 不像汽车零部件有集中听音工位 |
| 投资回收期 | 6-24 月 | 取决于是否被大客户绑定 |
| ROI 最高来源 | 漏检降低 (50-70%) + 设备停机减少 (20-40%) | |

**逻辑与汽车零部件不同**——不是省人力，是防事故。一个零件在 AMAT 产线上出问题 = 供应链信任崩塌。

## ROI 测算通用公式

```
年节省 = 人力替代节省 + 报废/退货减少 + 客诉/召回降低 + 设备停机减少 + 审核加分

投资回收期(月) = (总投资 / 年节省) × 12

其中：
  人力替代节省 = 替代听音工人数 × 年薪 × 轮班系数
  报废/退货减少 = 年报废量 × 单件成本 × AI 改善率
  客诉/召回降低 = 年客诉次数 × 单次平均损失 × 预计降低比例
  设备停机减少 = 年非计划停机次数 × 单次损失 × 预计降低比例
```
