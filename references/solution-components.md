## 一、方案体系总览

完整的工业声学AI质量链由四个平台级组件构成，覆盖从研发/实验室到产线量产再到运营层：

| 组件 | 定位 | 核心能力 |
|------|------|---------|
| **声学AI在线检测系统** | 产线 EOL 在线检测，替代人工听音 | 100% 全检，AI 实时 OK/NG 判定，PLC/MES 联动 |
| **多维声学分析平台** | 研发/实验室数据分析，替代黑盒分析软件 | 异音分析、模型开发、心理声学评估、报告生成 |
| **智能远程运维平台** | 设备健康远程监控与运维闭环 | 设备状态远程监控、异常预警、关键零部件健康度评估与剩余寿命预测 |
| **生产运营数据工作站** | 运营层数据汇聚与异常处置调度 | 质量数据汇聚、定时报告、换型与异常通知分发 |

> **全流程服务匹配**：研发/打样期 = 分析平台（声学基线与标准对齐）→ 量产检测 = 在线检测系统（EOL 全检判定）→ 设备侧 = 远程运维平台（健康闭环）→ 运营层 = 运营数据平台（数据汇聚与处置调度）。

## 二、在线检测系统：典型四层架构

```
接触式传感器 → 多通道采集器 → AI 边缘推理工作站 → PLC/MES 联动
   [感知层]       [采集层]         [AI 推理层]        [决策执行层]
```

### 感知层 — 接触式传感器（"电子听诊器"）

- 类型：压电陶瓷加速度计（剪切型结构），接触式机械耦合，直接采集结构振动
- 选型要点：频响覆盖目标异音主要频段、灵敏度与量程匹配工况、安装方式与工装兼容
- 与自由场麦克风互补：高噪声产线环境（70-80dB）下接触式通道信噪比优势显著

### 采集层 — 多通道数据采集器

- 多通道同步采集，IEPE 恒流源供电
- 采样率覆盖 AI 推理需求（16kHz 起步，更高采样率按目标频段规划）
- 产线部署，数据不出厂

### 推理层 — AI 边缘推理工作站

- 工控级硬件 + GPU 推理
- 判定模型：声纹基线 + 深度异常检测双范式；逐台全检，秒级以内出判定
- 阈值可调、判定结果与原始数据全量可追溯

### 执行层 — PLC/MES 联动

- 判定结果实时推送 PLC（放行/复检/拦截）
- 数据回传 MES/QMS，支持批次追溯与报表

## 三、多维声学分析平台

研发/实验室侧的分析平台，核心价值：

- **异音分析**：时频域分析、阶次分析、心理声学指标（响度/尖锐度/粗糙度/音调度）
- **模型开发**：AutoML 式小样本建模、模型蒸馏下发到产线推理节点
- **标准对齐**：把"老师傅的耳朵"变成文档化的声学检测标准
- **报告生成**：一键输出对标报告，支撑客户审核

## 四、典型交付流程

| 阶段 | 内容 | 交付物 | 责任方 |
|------|------|--------|--------|
| **S0 声学标准对齐** | 客户质量标准调研、良品/NG 样机联合评审、检测标准文档化 | 声学检测标准文档、参考样机清单 | 客户质量团队 + 方案商 |
| **S1 设备部署** | 现场勘查、声学环境评估、设备安装、PLC 联调、系统集成 | 安装报告、联调通过 | 客户生产团队 + 实施工程师 |
| **S2 数据采集** | 正常品/异常品声音数据采集、初步数据清洗与标记 | 数据集、数据报告 | 实施工程师 + 数据评审专家 |
| **S3 算法开发** | 数据标记、模型训练、迭代优化、性能验证 | 模型文件、性能测试报告 | 数据评审专家 + 算法工程师 |
| **S3.5 双轨验证** | AI vs 人工并行比对（≥1000 台）、Gauge R&R 测量系统分析 | 双轨比对报告、MSA 分析报告 | 客户质量团队 + 方案商 |
| **S4 验收上线** | 正式验收、操作培训、文档交付、售后启动 | 验收报告、操作手册、培训材料 | 客户验收团队 + 项目团队 |

## 五、渐进式商业模型框架（通用七档）

按客户技术能力与需求深度对号入座，从纯软件授权到全量交付+维保。**对外报价一律按项目评估，不引用具体档位价格**：

| 模式 | 类型 | 内容要点 | 适合客户 |
|------|------|---------|---------|
| **模式一 · 机理 SDK** | 纯软件授权 | 分析平台 SDK 授权，客户自备硬件+自实施 | 有声学团队的客户 |
| **模式二 · 机理调参** | SDK + 模型调参 | 模式一 + 机理模型节点调参服务 | 有团队缺经验的客户 |
| **模式三 · AI 助理辅助** | 软硬件+AI 助理 | 一体机 + 采集套装 + 传感器 + AI 助理远程服务，客户自主实施 | 中等能力客户 |
| **模式四 · 标准交付** | 软硬件+完整实施 | 一体机 + 采集套装 + 模型调参 + 完整项目管理 | 多数量产客户 |
| **模式五 · 自迭代** | AI 算力硬件 + AI 助理 | AI 一体机 + 交互终端 + 多项 AI 数字助理 | 需要自主运营的客户 |
| **模式六 · 算法深度调优** | 算法调优 + 全流程交付 | AI 硬件 + 算法深度调优 + 项目管理 + 验收 + 维保 | 高要求客户 |
| **模式七 · 全量服务** | 全量算法 + 服务 + 维保 | AI 硬件 + 全量算法 + 数据标记服务 + 全流程交付 + 维保 + 异地支持 | 无算法团队客户 |
